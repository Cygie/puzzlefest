# Implementation Walkthrough: Print view (A4)

## Summary

Every puzzle can be printed on A4 from the play screen: a clean page with title, details, a bordered grid, a word list with tick boxes and blanks for the solution word, plus an optional answers page.

## Structure Overview

`PrintSheet` is always rendered next to the play UI but only displayed in `@media print`; the interactive UI is wrapped in `.no-print`. `window.print()` therefore prints exactly the sheet.

## Key Implementation Details

### 1. Grid sizing

Cell size = min(180 mm / width, 175 mm / height, 12 mm), so any 5–20 grid fits the page with room for the word list; letters at 55% of the cell.

### 2. Answers page

`break-before: page`; same grid with a translucent stroke per word (from the stored placement) and shaded solution cells.

## Decisions Made

| Decision | Choice | Rationale |
|----------|--------|-----------|
| Print mechanism | Hidden print-only DOM + `window.print()` | No PDF library; works in Chrome on Android (print / save as PDF) |
| Units | mm | Predictable physical size on paper |
