# Project Constitution

> Universal policies that apply to ALL code in this project.
> This file is always inherited from root — modules cannot override it.

## Git Workflow

- **Commit Style**: Conventional commits (feat:, fix:, chore:, docs:, refactor:, test:)
- **Branch Strategy**: Solo project — small changes may go straight to `main`; larger features on a feature branch, merged when done
- **Main Branch**: `main` always builds and passes tests

## Code Review

- Solo project: no mandatory PR review
- Every run ends with a self/AI code review (review-report.md) before the work item is marked complete

## CI/CD

- No CI platform configured yet
- `npm run lint`, `npm run test` and `npm run build` must pass locally before committing

## Security Policies

- **No secrets in code** — use environment variables if ever needed
- Dependencies only from npm, pinned via `package-lock.json`
- No credentials, API keys, or tokens in source control
- No user data leaves the device (everything stored locally)

## Language

- **UI language**: Dutch (nl-NL) for all user-facing text
- **Code language**: English for identifiers, comments and docs

## Documentation

- README kept up to date with setup, run and install-on-Android instructions
