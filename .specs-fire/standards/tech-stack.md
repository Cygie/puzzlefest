# Tech Stack

## Overview

Client-only Progressive Web App (PWA). Built with Vite + React + TypeScript, installable on Android from the browser and fully usable offline. No backend. Can later be wrapped with Capacitor for a Play Store release.

## Core Technologies

### Language

**Primary**: TypeScript (strict mode)
**Version**: 5.x

### Framework

**Framework**: React
**Version**: 18.x / 19.x (latest stable at scaffold time)
**Rationale**: Component model scales well as more puzzle types are added; large ecosystem; good PWA tooling via Vite.

### Runtime

**Runtime**: Browser (Chrome for Android primary target); Node.js for tooling
**Version**: Node 22 LTS

## Data Layer

### Database

**Type**: None (client-side only)
**Database**: `localStorage` for settings and saved puzzles
**Version**: n/a

### ORM / Data Access

**Tool**: Small typed storage helper module
**Rationale**: Data volume is tiny; no need for IndexedDB yet.

### Caching

**Solution**: Service worker precache (vite-plugin-pwa / Workbox) for offline use

## API Layer

### API Style
